# Magical Princess Save Editor (Open Source)

Unofficial, open-source save editor for **Magical Princess** (Steam) by
Neotro Inc. / MAGI Inc.

## Features

- Browse all 31 save slots (player name, loop, date, level summary).
- Edit any value in the save as a JSON tree: money, stress, black coins,
  action points, skill points, the 7 stat levels, father favor, items, flags...
- Quick-edit panel for the most common values.
- Game settings editor: resolution tier (up to 3840x2160), fullscreen,
  quality, vsync, language, volumes, text speed.
- Every write creates a timestamped backup in the save folder's backups/
  subfolder. Safe by design.

## How to use

1. Close the game first.
2. Run MagicalPrincess.SaveEditor.exe (no installation needed).
3. Pick a slot, edit values, press Save.
4. Launch the game and load the slot.

## Notes

- Open source (MIT): <https://github.com/PensiveFei/MagicalPrincess-SaveEditor>
- Contains no game assets and does not modify the game program.
- Unofficial fan tool, not affiliated with Neotro Inc. / MAGI Inc.
- Steam Cloud syncs edited saves normally.
- Use sensible values — extreme numbers may break balance or achievements.
